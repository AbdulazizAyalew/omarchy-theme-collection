# Rain District

A cinematic dark Omarchy theme built around four real Tokyo photographs.

The palette uses asphalt-black surfaces, weathered teal focus colors, warm
taxi-amber highlights, and quiet off-white text. Translucent shell surfaces
keep the photograph visible without sacrificing readability.

The wallpaper rotation moves from dense neon streets to a quiet stone lane.
Every image is a real photograph; no generative imagery is used.

Use `omarchy theme bg next` to cycle through the four wallpapers.
