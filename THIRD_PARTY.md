# Third-party themes and assets

The following themes were collected from their upstream repositories. Their
original README and license information are preserved inside each theme
folder.

| Theme | Upstream | Imported revision | License stated upstream |
| --- | --- | --- | --- |
| Adrift | https://github.com/jaredb1011/omarchy-adrift-theme | `dd464cb73aea0bb7c2a3129709bb8805a437b85e` | MIT |
| Azure | https://github.com/tahfizhabib/omarchy-azure-theme | `0ebafd0f3487c9d041b678ea91cbcd468cea963e` | MIT (README) |
| Brutalism | https://github.com/bjornramberg/omarchy-brutalism-theme | `21c9887ce86e8357d3c8a90a9c1d1764294e0de7` | GPL-3.0 |

The collected Azure copy contains one local safety change: its unpinned remote
Discord CSS import is disabled. The remaining Azure color variables are kept.

Wallpaper and photography credits for GT3 Nocturne, Rain District, and Aquila
Noctis are documented in each theme's `SOURCE.md`. Those notices must remain
with redistributed copies.
